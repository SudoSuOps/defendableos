# expected_outputs/

Placeholder for canonical reference outputs from validated calibration
runs. Populated after the first agent calibration produces structured
outputs validated against `schemas/task_result.schema.json` and
`schemas/adversarial_result.schema.json`.

Once populated, this directory holds one JSON file per task and per
adversarial case · the HONEY-pass canonical output that the Tribunal
uses as a comparison anchor for regression testing across agent
versions.
