# data/claw-bakery/ · Claw Bakery local-driver storage

This directory is the **LocalDriver** storage root for the Claw Bakery
in dev (see `services/api/app/services/claw_bakery/bakery_storage.py`).

It is **gitignored** because it is mutable state generated by:

- every `POST /api/v1/agent-swarm/clawcheck/intake` (raw intake + snapshot)
- every `defendable-agentgrade run --pack packs/refund_agent_v1 ...` followed
  by `ingest_benchmark_run(...)` (benchmark artifacts + receipts + events
  + pair candidates)
- every ClawForge generation (when explicitly enabled)

## Production

In production the bakery uses the S3 driver pointed at the existing
`s3_private_evidence_bucket` (configured in `services/api/app/core/config.py`).
This directory does not exist in production.

## Reset

```bash
rm -rf data/claw-bakery && mkdir -p data/claw-bakery
```

## Public-safe subset

The public-safe subset of bakery artifacts (the founder-spec 6-file output
of an AgentGrade refund-batch run) is preserved separately under
`data/agentgrade-receipts/refund-batch-001/`, which has its own
Evidence-Vault `.gitignore` allowlisting the safe files.
